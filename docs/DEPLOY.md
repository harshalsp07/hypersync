# HyperSync Engine — Split Deployment Guide

## Architecture

```
┌─────────────────────────────────────────────────────┐
│                    Vercel (Free)                     │
│  ┌───────────────────────────────────────────────┐  │
│  │  React Frontend (Vite)                        │  │
│  │  https://hypersync.vercel.app                 │  │
│  └───────────────────────────────────────────────┘  │
└──────────────────────────┬──────────────────────────┘
                           │ WebSocket (wss://)
                           ▼
┌─────────────────────────────────────────────────────┐
│                    Your VPS                          │
│  ┌──────────┐  ┌──────────┐  ┌──────────────────┐  │
│  │  Nginx   │  │  Node.js │  │  Redis + PG      │  │
│  │  :443    │→ │  :3000   │→ │  :6379 / :5432   │  │
│  │  (SSL)   │  │  (WS)    │  │  (internal)      │  │
│  └──────────┘  └──────────┘  └──────────────────┘  │
└─────────────────────────────────────────────────────┘
```

## Step 1: Deploy Backend to VPS

```bash
# SSH into your VPS (Oracle Cloud, Hetzner, etc.)
ssh root@your-vps-ip

# Clone the repo
git clone <your-repo-url> && cd hypersync-engine

# Deploy backend
./scripts/deploy.sh hypersync.vercel.app
```

This starts:
- Node.js WebSocket server on port 3000
- Redis on port 6379 (internal)
- PostgreSQL on port 5432 (internal)

## Step 2: Deploy Frontend to Vercel

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com) → Import Project
3. Select your repo
4. Configure:
   - **Framework Preset:** Vite
   - **Build Command:** `pnpm --filter @hypersync/shared build && pnpm --filter @hypersync/web build`
   - **Output Directory:** `apps/web/dist`
5. Add Environment Variables:
   ```
   VITE_WS_URL=wss://your-vps-ip:3000
   VITE_API_URL=https://your-vps-ip:3000
   ```
6. Deploy!

## Step 3: Point Your Domain

1. Go to your domain registrar
2. Add CNAME record:
   ```
   sync  →  cname.vercel-dns.com
   ```
3. In Vercel dashboard, add the domain to your project
4. Enable HTTPS (automatic with Vercel)

## Environment Variables

### VPS (.env.prod)
```bash
REDIS_PASSWORD=<auto-generated>
PG_USER=hypersync
PG_PASSWORD=<auto-generated>
PG_DB=hypersync
JWT_SECRET=<auto-generated>
CORS_ORIGIN=https://sync.yourdomain.com
PORT=3000
```

### Vercel (Dashboard)
```
VITE_WS_URL=wss://sync.yourdomain.com
VITE_API_URL=https://sync.yourdomain.com
```

## Commands

| Action | Command |
|--------|---------|
| Deploy backend | `./scripts/deploy.sh sync.yourdomain.com` |
| Update backend | `./scripts/update.sh` |
| View logs | `docker compose -f docker-compose.prod.yml logs -f` |
| Restart backend | `docker compose -f docker-compose.prod.yml restart` |
| Stop backend | `docker compose -f docker-compose.prod.yml down` |
| Backup database | `./scripts/backup.sh` |
